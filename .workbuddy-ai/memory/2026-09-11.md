# 2026-09-11

## plm Qt frontend layout fixes (workbuddy-ui-dev)

Investigated Qt frontend issues reported by user. The debug screenshots in
`plm/work/` showed layout breakage caused by a saved font size of 18.5 px;
fixed UI chrome (sidebar, topbar, lane grid, tables) was designed against a
13 px baseline and did not scale.

Changes on branch `workbuddy-ui-dev`:
- `src/plm/frontend/qt/widgets/settings.py`: clamp font-size range to 11-16 px.
- `src/plm/frontend/qt/main_window.py`: clamp applied font size, add
  `_ui_scale()` helper, scale sidebar/topbar/tab-bar sizes with font.
- `src/plm/frontend/qt/widgets/lanegrid.py`: add `_ui_scale()` helper, scale
  lane column/mode/action widths, replace palette QHBoxLayout with wrapping
  `_FlowLayout`, scale palette swatch stylesheet.
- `src/plm/frontend/qt/widgets/tables.py`: add `_ui_scale()` helper, scale
  fixed column widths, minimum section size, and row height.

Validation:
- Reproduced the broken layout at 18.5 px using `work/reproduce_qt_issues.py`.
- Confirmed Settings dialog clamps 18.5 -> 16.0.
- Ran `work/qt_smoke_test.py`: tab switching, table insert/delete, lane paint OK.
- Ran `python -m unittest discover -s tests`: 11 ok, 5 skipped (Flask not
  installed), no new failures.
- Committed: `6083a4b fix(plm-qt): scale fixed UI sizes with font size and
  clamp font range`.
