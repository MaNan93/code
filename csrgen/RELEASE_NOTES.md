# csrgen Release Notes

本文按本地 wheel 与源码差异整理，记录 0.1.0～0.1.15 各版本相对上一版本的改动。0.1.0～0.1.11 均在 2026-10-10 构建，0.1.12 于 2026-10-11 按源码改动整理，0.1.13～0.1.15 于 2026-10-13 整理；这些版本号不代表已创建 GitHub Release 或发布到 PyPI。

当前版本为 **0.1.15**。各版本共享 APB3 接口、固定 32-bit 数据宽度、无 PSTRB、默认 16-bit 地址宽度，以及 openpyxl 3.1.5 兼容性。

## 0.1.15 — 设计文档与重新构建（2026-10-13）

- 新增 docs/DESIGN.md，说明六层职责、数据结构、配置、地址/字段/reserved 校验、APB3 时序、访问属性、工具诊断、扩展接口及发布验证。
- README 与架构文档加入设计文档入口，设计文档随源码包分发。
- 版本从 0.1.14 升至 0.1.15，重新构建 sdist 和 wheel；Python 业务源码、CLI 接口和默认 RTL 行为与 0.1.14 一致。
- 验证：92 项 Python 测试通过；wheel 完整性、版本和源码一致性、源码包文档、安装后的默认生成及审查/格式化流程验证通过。

## 0.1.14 — 分层重构与可选审查/格式化（2026-10-13）

- 将单个 generator 拆为文件读入、表格布局、寄存器解析/规范校验、RTL 生成、代码质量审查和可选格式化。使用独立寄存器模型，`pipeline.py` 组织流程，`generator.py` 保留为兼容入口。
- 保留现有 `read_xlsx()`、`generate_rtl()`、CLI 默认值及警告类型；默认 B:G 模板生成的 RTL 与原示例逐字一致，不改变 APB3、W1C、RWSC、reserved 或读保持行为。
- 新增 `--header-rows`，默认 1，无 header 时明确设置为 0；不根据 header 内容自动猜测。
- 新增 `--column FIELD=COLUMN`，支持 Excel 列字母或 1-based 数字，支持忽略 description，检查必需列缺失、列冲突和重复配置。
- 文件读入返回原始单元格与实际行号；为后续 CSV 读入、编码配置预留适配器接口。内置读入目前仍只支持 XLSX，CSV 尚未作为内置格式开放。
- 新增可选 `--lint`（Verilator）与 `--format`（Verible），可以指定工具路径。同时启用时，在格式化前后分别审查；工具缺失、失败、超时或格式化输出为空会报错，不覆盖已有输出。
- 源码包包含示例、RTL 测试、release note 和分层架构文档，方便独立验证。
- 验证：92 项 Python 测试通过，包括原有 70 项回归、布局配置、格式适配器扩展和真实审查/格式化；默认生成的 RTL 与原示例一致。

## 0.1.13 — 本地 wheel 更新（2026-10-13）

- 从 0.1.12 升级为 0.1.13，基于当前源码重新构建本地 wheel 和 sdist。
- 同步 README 的当前版本；生成接口与 RTL 行为保持不变，无需迁移。
- 验证：70 项 Python 测试通过；本地 wheel 安装及命令行入口检查通过。未单独提交或发布。

## 0.1.12 — 重复 Offset 报错，数字单元格警告

- 同一个 Offset 被其他 Offset 隔开后再次出现时报错并停止生成，错误信息包含两处行号，例如 `row 4: duplicate register offset 0x4, already defined at row 2`。此前两段字段会被静默合并为一个寄存器。
- 同一寄存器的连续行重复填写相同 Offset、留空沿用上一个 Offset、合并单元格及空行的行为不变。
- Offset 或复位值为 Excel 数字单元格且数值不小于 10 时输出警告，指出按十进制使用的实际值及对应的十六进制文本写法；仍按十进制继续生成，退出码为 0。0～9 两种读法相同，不警告。
- 提供 `NumericCellWarning` 并从包中导出；CLI 以 `csrgen: warning:` 显示。reserved 行的复位值始终覆盖为 0，不参与此项警告。
- 生成的 RTL 与 0.1.11 完全一致，无需重新生成。
- 验证：70 项 Python 测试通过；示例 RTL 重新生成后无差异；APB 读写、reserved、rwsc 三项行为仿真通过。

## 0.1.11 — 统一 logic，简化寄存器输出

- 模块的所有输入、输出及内部信号统一声明为 `logic`，对齐端口声明。
- `prdata` 和 `rw`、`rw1c`、`rwsc` 字段直接由 `always_ff` 驱动，移除 0.1.9 引入的内部 `prdata_q`、`<signal>_q` 及连接输出的 `assign`。
- 移除已不存在的内部 `*_q` 名称限制；表格中的信号名称仍须满足标识符、重名和实际内部信号冲突检查。
- 保留 `AW`、`OFFSET_0x<offset>`、`csr_reg_data_0x<offset>` 命名、集中声明、多行拼接及 bit/reset/access 行尾注释；不输出表格 description。
- 验证：68 项 Python 测试通过；`AW=3/16/24/32` 的 RTL 检查通过；APB 读写、reserved、rwsc 三项行为仿真通过；wheel 安装后生成结果与源码示例一致。

## 0.1.10 — 不再输出 description

- G 列 description 仍作为表格元数据读取，但不再生成到 RTL 注释中。
- 删除描述换行、显示列宽折行逻辑及相应依赖。
- 保留拼接行尾的 bit 范围、reset 值、访问属性，以及必要的读采样与 rw1c 优先级说明。
- 确认地址常量及其读写引用均使用 0.1.9 引入的 `OFFSET_0x<offset>`，无旧的 `CSR_ADDR_...` 名称。

## 0.1.9 — 按 offset 命名，地址宽度参数改为 AW

- 地址常量从 `CSR_ADDR_00000004` 改为 `OFFSET_0x4`；声明、地址命中判断、读选择、写判断同步修改。
- 每个地址的读值从序号命名 `csr_reg_data_1` 改为 `csr_reg_data_0x4`。十六进制字母使用小写，例如地址 0x1C 对应 `OFFSET_0x1c` 和 `csr_reg_data_0x1c`。
- RTL 地址宽度参数从 `aw` 改为 `AW`，地址端口、常量位宽及类型转换同步修改。CLI `--aw` 和 Python 函数的 `aw` 参数保持不变。
- 当时按要求省略端口的 `wire/reg/logic`，使端口默认作为 wire；引入内部 `logic prdata_q`、`logic <signal>_q` 和输出连接赋值，以保证时序赋值合法。此端口风格在 0.1.11 被统一 logic 取代。
- 精简重复的地址、字段 bit/reset/access、reserved 和 storage 注释；description 当时仍保留，并在 0.1.10 移除。
- 更新生成名称的冲突检查，防止表格字段与新的地址常量、读值信号、内部寄存器同名。

## 0.1.8 — 拼接赋值每行一个字段

- `csr_reg_data_*` 的拼接改为多行，每行一个字段或连续 reserved 位段，按 bit 31 到 bit 0 排列。
- 每行末尾标注单 bit 或 bit 范围、带位宽的十六进制 reset 值及访问属性。
- reserved 位段标注 reset=0、ro、tie0；正确处理最后一个字段无逗号的语法。
- 完整 32-bit 字段及全 reserved 地址也使用同一拼接格式。

## 0.1.7 — 声明附带 offset 注释

- 每条 `csr_reg_data_*` 声明末尾增加实际地址的十六进制 offset 注释。
- 地址不连续时，注释仍对应表中的实际 offset，代码行为不变。

## 0.1.6 — 集中声明，每个地址一条拼接赋值

- 将所有 `csr_reg_data_0`～`csr_reg_data_n` 声明移到模块内部信号声明区。
- 将分散的字段读映射合并为每个地址一条拼接 `assign`，包括显式 reserved、高位、低位及字段之间空隙的补零。
- 字段描述和 bit 范围集中放在该地址的拼接前；写逻辑放在拼接后。
- 中央 `always_comb` 继续只负责按地址选择完整 32-bit 读值。

## 0.1.5 — 按地址组织读映射与写逻辑

- 为每个地址定义独立的 32-bit `csr_reg_data_0`～`csr_reg_data_n`。
- 在各地址区域使用字段级 `assign` 组装读值，让 RO 注释旁边有实际输入映射；RW/W1C/RWSC 的读映射与写逻辑放在同一区域。
- 中央读选择从逐字段赋值改为选择完整地址读值，内部组合读信号从 `csr_rdata` 改名为 `csr_data`。
- 增加生成读值信号名称的冲突检查。

## 0.1.4 — rwsc、完整读保持、多行描述

- 新增 `rwsc` 属性，支持单 bit、多 bit 和完整 32-bit 字段。有效 APB 写入对应数据，写入的 1 保持一个时钟周期；下一个没有新有效写入的时钟沿自动清零，写 0 不产生置位脉冲，新有效写入优先于清零。
- 移除未选中及写操作时清零 `prdata` 的分支。从本版起，`prdata` 只在复位或有效读 SETUP 采样时更新，空闲、写操作和未命中读地址均保持当前值。
- description 注释保留 Excel 换行，长段落按约 72 个显示列折行，中文按双列计算。此功能在 0.1.10 按新要求移除。

## 0.1.3 — 未命中读地址保持数据

- 移除读地址未命中时将 `prdata` 清零的分支，未映射或非对齐读在 SETUP/ACCESS 阶段保持访问前的数据。
- ACCESS 阶段仍通过 `PSLVERR` 报告地址错误。
- 本版空闲及写操作仍会清零 `prdata`；这一行为在 0.1.4 修改为保持。

## 0.1.2 — reserved 强制 RO/tie0，自动补齐 32 bit

- 显式 `reserved` 不生成端口或状态寄存器，始终按 reset=0、ro、tie0 处理。
- 表中的 reserved reset/access 与该规则不一致、缺失或无效时，输出含行号和地址的警告并继续生成。
- 每个地址视为完整 32-bit 寄存器，未定义的高位、低位及字段间空隙均自动按 reserved 补零。
- reserved 位段越界或与其他字段重叠仍报错。
- 提供 `ReservedFieldWarning`，CLI 显示警告而不重复报告。

## 0.1.1 — 固定模板列读取，不匹配表头

- 从表头名称识别改为严格读取固定 B:G 列：offset、signal、reset、bit、access、description。
- 跳过第 1 行，自第 2 行开始读数据，不匹配或检查表头文字；A 列及 G 列以后的内容忽略。
- 保留空行、合并 offset 单元格和空 offset 沿用上一个地址的支持。

## 0.1.0 — 初始工具与 wheel

- 提供 `csrgen.py`、`python -m csrgen` 和安装后的 `csrgen` 命令，支持创建截图格式的示例 XLSX。
- 读取 XLSX，默认 sheet1，可指定 sheet；sheet 名优先精确匹配，再忽略大小写匹配。本版按表头名称读取，表头匹配忽略大小写；0.1.1 改为固定列位置读取。
- 生成可综合 APB3 SystemVerilog，默认模块和文件为 `apb_csr`、`apb_csr.sv`，无 PSTRB，数据固定 32 bit，地址宽度由当时的 RTL 参数 `aw` 控制，默认 16，生成阶段支持 2～32 bit。
- 模块名前缀和文件名前缀独立设置，并支持指定完整模块名及输出路径。
- 支持 `rw`、外部状态输入 `ro`、按位清零的 `rw1c`。W1C 配置同宽 `<signal>_hwset` 输入；软件写 1 清对应位，写 0 无动作，硬件置位与软件清零同时发生时置位优先。
- `prdata` 为寄存器输出，在读 SETUP 结束的时钟上升沿采样，ACCESS 保持，`PREADY=1`，无需额外等待周期。本版空闲、写操作和未命中地址时会清零，分别在 0.1.3、0.1.4 调整。
- 对未映射或非对齐地址在 ACCESS 返回 `PSLVERR`；检查地址范围、字段重叠、reset 位宽及信号名称冲突。
- 支持显式 reserved 读零；本版要求表中 reset=0、access=ro，不符则报错，0.1.2 改为警告并覆盖。
- 依赖 openpyxl，Python 3.10+；提供 wheel、源码包、示例和 Python/RTL 测试。生成 RTL 不含 `synthesis translate_off/on` 或 `initial` 参数检查段。

## 升级到 0.1.12

- 从 0.1.11 升级无需重新生成 `.sv`。表格中若有被隔开的重复 Offset，须合并到同一段或改正地址；出现数字单元格警告时，核对实际地址和复位值，建议将这两列改为文本格式。
- 从更早版本升级时，同时适用以下各项。

- 重新生成 `.sv`；已有实例化代码中的 `#(.aw(...))` 必须改为 `#(.AW(...))`。命令行仍使用 `--aw`。
- 如测试平台、约束或脚本引用内部层次名称，更新 `CSR_ADDR_...`、序号形式 `csr_reg_data_*` 及 0.1.9 的 `*_q` 名称。
- 输入表格须遵循 B:G 固定模板；旧版仅靠表头名称定位、列位置不同的表格需要调整。
- RO 的表格 reset 值只作为元数据，不复位外部状态输入；reserved 的 reset/access 统一覆盖为 0/ro；description 不进入 RTL。
- 读未命中、写操作及空闲均保留最近一次有效读采样的 `prdata`。rwsc 在写入后的下一时钟沿清零，W1C 的硬件置位优先级保持不变。
